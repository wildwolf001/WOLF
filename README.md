# WOLF - Wise Operations & Logic Framework

WOLF 是 AI 协作平台，致力于为开发者提供更智能的任务分解与执行方案。本项目基于前后端分离架构设计，支持多种 Agent 角色在同一平台内协同工作。


## 🚀 技术栈

- **后端**：FastAPI, Uvicorn, Pydantic, SQLAlchemy, Redis, WebSockets
- **前端**：React 18, TypeScript, Vite, Tailwind CSS, Zustand, Axios, Socket.IO-client
- **数据库**：PostgreSQL (通过 asyncpg), SQLite (本地开发)

## 🔧 环境要求

- Python 3.11+
- Node.js 18+
- Conda（可选，用于环境管理）
