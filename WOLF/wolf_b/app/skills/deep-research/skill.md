# Deep Research Skill

## Description
深度研究技能，用于全面研究复杂话题

## Capabilities
- 文献综述
- 信息收集和整理
- 多角度分析
- 报告生成

## Usage
当用户需要深入研究某个主题、进行文献综述或全面分析时使用。

## Approach
1. **确定研究范围**: 明确研究目标和关键问题
2. **收集信息**: 使用搜索工具、网络获取等多种渠道
3. **整理分析**: 归类信息，识别关键发现
4. **综合报告**: 将研究发现整理成完整报告

## Tools
- `search_web(query)`: 网络搜索
- `fetch_web(url)`: 获取网页内容
- `read_file(path)`: 读取本地文件
- `knowledge_service.search(query)`: 知识库检索

## Output Format
```
## 研究主题
[主题]

## 研究目标
[具体目标]

## 关键发现
1. [发现1]
2. [发现2]
...

## 详细分析
[深入分析]

## 结论
[总结和结论]

## 参考文献
- [来源1]
- [来源2]
```

## Notes
- 研究需要多角度、多来源
- 保持客观中立
- 标注信息来源
