# Web Research Skill

## Description
网络研究技能，用于搜索和获取网络信息

## Capabilities
- 网络搜索
- 网页内容提取
- 信息整理和归类

## Usage
当用户需要从互联网获取信息、进行研究或验证最新内容时使用。

## Tools
- `search_web(query, num_results=5)`: 搜索网络
- `fetch_web(url, selector=None)`: 获取网页内容

## Examples
- "搜索最新的AI研究成果"
- "获取维基百科关于深度学习的页面"
- "搜索并总结关于React最新版本的信息"

## Process
1. **搜索**: 使用相关关键词搜索网络
2. **获取**: 提取关键网页的内容
3. **整理**: 归类和组织信息
4. **报告**: 生成结构化报告

## Safety
- 只访问公开可用的网页
- 不执行登录或认证操作
- 不下载可执行文件
